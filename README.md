# تابلو آنلاین قیمت طلا: چهار طرح

چهار طرح متفاوت UI برای تابلو قیمت طلافروشی (تلویزیون و نمایشگر فروشگاهی). همه راست‌به‌چپ هستند، ارقام فارسی دارند و با HTML/CSS ساخته شده‌اند تا مستقیم به Next.js منتقل شوند.

| طرح | فایل | تم | صحنه |
|---|---|---|---|
| زرنگار | `boards/noir.html` | مشکی و طلایی | ۱۹۲۰×۱۰۸۰ |
| صدف | `boards/ivory.html` | روشن صدفی و زمردی | ۱۹۲۰×۱۰۸۰ |
| بازار | `boards/navy.html` | داشبورد سرمه‌ای با نمودار | ۱۹۲۰×۱۰۸۰ |
| ستون | `boards/portrait.html` | شرابی و رزگلد، عمودی | ۱۰۸۰×۱۹۲۰ |

- `index.html`: گالری معرفی طرح‌ها برای کارفرما
- `design-system.html`: اصول، مقیاس تایپوگرافی با فاصله‌ی خوانایی، رنگ‌ها، کامپوننت‌ها و قرارداد داده
- `tokens/tokens.json`: توکن‌ها در قالب Tokens Studio (چهار تم)
- `screenshots/`: تصویر کامل هر طرح برای ارسال
- `assets/board.js`: موتور مشترک (ساعت، تاریخ شمسی، نوسان نمونه، نمودار، مقیاس صفحه)

## اجرا

کافی است `index.html` را در مرورگر باز کنید. اگر به آدرس تابلو `?still` اضافه کنید، نوسان قیمت متوقف می‌شود (برای گرفتن اسکرین‌شات).

## انتقال به Figma

1. پلاگین **html.to.design** را در Figma نصب کنید و آدرس هر تابلو (یا فایل HTML) را با عرض ۱۹۲۰ وارد کنید. لایه‌ها به صورت فریم و متن قابل ویرایش وارد می‌شوند.
2. پلاگین **Tokens Studio** را باز کنید و `tokens/tokens.json` را وارد کنید تا رنگ‌ها و اندازه‌ها به صورت Variable/Style ساخته شوند. هر تم یک Mode است.
3. فونت‌ها: Vazirmatn، Noto Nastaliq Urdu، Markazi Text، Aref Ruqaa، Readex Pro و Lalezar (همه از Google Fonts).

نام فروشگاه («آوین»)، سازنده («تابان‌برد») و قیمت‌ها ساختگی‌اند.
